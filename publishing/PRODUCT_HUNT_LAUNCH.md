# Product Hunt & Show HN Submission Kit

## Product Name
**BRAVIA Control Center v3.0 Ultra**

## Tagline
Desktop power-user console & optimization suite for Sony BRAVIA Android TVs.

## Short Description
BRAVIA Control Center is an open-source, zero-cloud desktop web application that connects wirelessly to your Sony BRAVIA TV over ADB. Audit hardware, tune performance profiles, calibrate 4K display & sound engines, debloat telemetry, and manage launchers from your browser.

## Key Features
- 🗂 Persistent Sidebar Navigation & Dark Hardware Console UI
- 🎛 Simple / Advanced Mode Toggle
- 🔍 Global Command Palette (`⌘K` / `Ctrl+K`)
- 🚀 1-Click Hardware GPU Composition & RAM Cleaner
- 🛡️ 20-Package Safe Debloater (Samba TV ACR, Sony Bug Collectors, Google TV Ads)
- 📱 Live App Utilization Telemetry (Audit PSS Memory across 52+ installed apps)
- 📸 Multi-Tier Snapshot & Restore System (Host JSON, Browser LocalStorage, On-TV Storage)
- 📦 Drag-and-Drop APK Sideloader
- 🎮 Virtual Remote Control & Desktop Keyboard Shortcuts
